# Информационно-аналитическая система выбора наилучшего района для жизни

Веб-приложение для многокритериальной оценки и ранжирования районов Республики Беларусь на основе официальных статистических данных Белстата и открытых картографических источников. Система позволяет настраивать весовые коэффициенты для 13 социально-экономических критериев, отображает интерактивную хороплет-карту и формирует динамические рейтинговые таблицы.

---

## Архитектура проекта

Проект разделен на две независимые подсистемы:
* **Backend:** REST API на базе FastAPI и Python, выполняющий загрузку исходных данных, нормализацию показателей по методу Min-Max и вычисление интегрального балла $R$.
* **Frontend:** клиентское веб-приложение на базе React, Vite и Tailwind CSS с картографическим модулем Leaflet.

## Системные требования

Перед развертыванием убедитесь в наличии следующего программного обеспечения:
* **Python** версии 3.10 или выше (с установленным пакетным менеджером `pip`).
* **Node.js** версии 18.x или выше (включая менеджер пакетов `npm`).

---

## Установка зависимостей

### 1. Серверная часть (Backend)

1. Откройте терминал и перейдите в директорию сервера:
   ```bash
   cd project_root/backend
   ```
2. (Рекомендуется) Создайте и активируйте виртуальное окружение:
   * **Windows:**
     ```cmd
     python -m venv venv
     venv\Scripts\activate
     ```
   * **Linux / macOS:**
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
3. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

*Состав библиотек Python:* `fastapi`, `uvicorn`, `pydantic`, `pandas`, `numpy`, `openpyxl`.

### 2. Клиентская часть (Frontend)

1. Откройте отдельное окно терминала и перейдите в директорию клиента:
   ```bash
   cd project_root/frontend
   ```
2. Установите зависимости проекта:
   ```bash
   npm install
   ```

*Состав ключевых библиотек JavaScript:* `react`, `react-dom`, `leaflet`, `react-leaflet`, `vite`, `tailwindcss`.

## Порядок запуска

Для работы системы необходимо одновременное функционирование обоих серверов.

### Шаг 1. Запуск Backend API

В терминале директории `backend` выполните команду:
```bash
uvicorn main:app --reload --port 8000
```
После успешного запуска сервер будет доступен по адресу:  
`http://localhost:8000`  
Документация Swagger UI доступна по адресу: `http://localhost:8000/docs`

### Шаг 2. Запуск Frontend

В терминале директории `frontend` выполните команду:
```bash
npm run dev
```
После компиляции локальный веб-сервер отобразит сетевой адрес:  
`http://localhost:3000`

### Шаг 3. Использование системы

Откройте в веб-браузере адрес `http://localhost:3000`. Интерфейс готов к работе:
* **Боковая панель:** переключение между базовым режимом (дискретные уровни важности) и расширенным режимом (слайдеры и числовой ввод весов).
* **Карта:** отображение районов с цветовой шкалой от 1 до 10 баллов и карточками сведений по клику.
* **Таблица лидеров:** автоматический вывод Топ-10 районов с двусторонней синхронизацией подсветки при выборе района на карте.
* **Таблица сравнения:** полноэкранный режим с детализацией по всем 13 критериям, нормализованным баллам и поисковым фильтром.
